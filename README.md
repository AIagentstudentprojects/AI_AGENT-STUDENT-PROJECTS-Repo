## Project Submission Requirements

Each student should submit the following items, as applicable:

1. Student details and project title.
2. Final project report in PDF format.
3. Source code or GitHub repository link.
4. README with installation and execution instructions.
5. System architecture or workflow diagram.
6. Testing results and screenshots.
7. Working application URL or demonstration video.
8. Additional files required for the project type.
